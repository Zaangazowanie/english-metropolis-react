# Practice game catalogue

The current catalogue contains 38 canonical games. See
[PRACTICE-ARCADE.md](PRACTICE-ARCADE.md) for their scene families, material
direction, architecture and runtime requirements.

The executable catalogue is `src/practice/shells3d/kit/registry.ts`.
`StudentPractice.tsx` supplies lesson puzzles to the same controllers used by
the public catalogue. City entries use session-local demo progress.

The previous wave-based concepts and duplicate practice storyboards were
retired at the user's request on 5 September 2026. They remain in Git history.
